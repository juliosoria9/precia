Tiendas y perfiles

Cada tienda tiene un perfil: la URL de búsqueda y los selectores CSS para leer sus fichas. Lo genera el 🤖 configurador una sola vez, el sistema lo valida y después se usa sin IA. Si la tienda cambia su HTML, el 🤖 reparador propone una versión nueva, que no se fija hasta que la revisas: «Reparado» quiere decir reparado por la IA y confirmado por ti.
