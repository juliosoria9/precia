Alertas

PrecIA vuelve a mirar los precios cada cierto tiempo y te avisa por email o Telegram cuando un producto baja del precio que fijes. Las alertas se crean desde la ficha de cada producto.

{% include "_lista_alertas.html" %}

Cómo funciona

  1. El planificador repite la búsqueda con los perfiles ya creados, sin IA y con la espera mínima entre peticiones a cada tienda.
  2. Cada precio se guarda en el histórico (SQLite).
  3. Si el mejor precio queda por debajo del objetivo, se envía el aviso una sola vez hasta que vuelva a subir.

El planificador y los avisos llegan en el hito H7.{% if es_demo %} Ahora mismo son datos de ejemplo.{% else %} De momento las alertas se guardan, pero todavía no se envía ningún aviso.{% endif %}
